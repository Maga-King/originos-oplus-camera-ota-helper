## 已实现

- 原生 Windows GUI + CLI 共用构建流程；便携版自带运行时和最小 LLVM 工具链。
- 选择目标 OriginOS、本机欧加原厂解包、输出目录；可选 dumpsys TXT。
- 可选只读 ADB 备用取材，多台在线设备必须选择；默认完全离线。
- cameraserver 按函数上下文动态定位包名注入、过滤保留、RAW/XPAN、流统计与时间戳补丁。对象字段相关 getter ABI 变化时停止，而非按旧偏移强写。
- XPAN照片尺寸读取原厂配置，包名tag来自可靠HAL导出或明确的离线编号；代码和 literal island 分离。
- SAT桥从源码编译并链接当前系统client副本，YUV两份提供者、视频缓冲均用当前系统原件。
- 杜比RPU封装修正、Vivo缩略图限定HEVC基础层抽帧；不改vivo相册APK。
- 独立杜比配置按所选原厂相对结构收集，包括odm深层配置；不依赖自动亮度模块运行。
- 完整应用组含7个APK：相机、相册、AppPlatform、AIUnit、StdID、VideoGallery、权限声明辅助APK；AI私有库及XML一并纳入。
- 安装/开机设置权限和标签，辅助摄像头名单只追加；不自动刷入、不自动重启、不清数据。
- 提供从零手动制作教程、来源清单、各阶段构建报告。

## 不能省略的边界

- 本轮生成的是开发测试包，未刷入手机。用户确认能用的是先前手工stage9，不应偷换成“自动生成版已实机完全验证”。
- 测试集是本机归档原件和部分配置，不是新的完整原厂ROM；缺CameraHWConfiguration、camera_unit_config、原厂Product美颜JNI和CIL，构建报告已逐项警告。当前并未证明另一款机型实机可用。
- 配套CRD/APS二进制仍有已声明例外；同SoC也不意味着所有传感器/ODM算法ABI兼容。美颜缺原厂匹配件时目前保留素材内版本并警告。
- GUI使用Windows原生ttk风格，不是重写的WinUI框架。
- 完整ColorOS私有EDR/满血ProXDR未确认；本轮补齐AI安装材料，不承诺全部联网模型服务已经恢复。
- 其他OTA若改变对象结构、寄存器或函数上下文，会明确停止对应补丁，需要新增规则，不以机型或序列号锁阻挡，也不把不匹配旧库硬塞过去。
